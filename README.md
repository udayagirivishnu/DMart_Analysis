# DMart Sales Analysis

## Project Overview
This project focuses on exploring and analyzing DMart sales data using Microsoft Excel to understand sales performance and identify useful business insights.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Excel formulas
- Data visualization

## Project Objectives
- Analyze sales data.
- Identify sales trends and patterns.
- Compare performance across different categories.
- Summarize findings to support business decisions.

## Analysis
The dataset was explored and analyzed using Excel features such as data organization, calculations, Pivot Tables, and charts.

## Key Insights
Key observations and findings are derived from the analysis of the dataset.

## Files Included
- Excel dataset and analysis workbook.

## Conclusion
This project helped develop practical skills in data analysis, organizing data, summarizing information, and communicating findings using Excel.
